Test des moteurs — 8 relevés

18 septembre 2026 · intention HT-01, la même aux huit · premier relevé sous le mode opératoire version 2.

Ce qu'on cherche, et rien d'autre : lequel des deux tient quatre relevés d'affilée sans mur de quota ni demande de connexion, et lequel cite réellement ses sources avec des liens. Ce n'est pas un test de visibilité : aucun taux n'en sortira.

D'affilée, sans pause. C'est le mur de quota qu'on veut voir ; une pause le masquerait. Les quatre ChatGPT d'abord, puis les quatre Perplexity.

ChatGPT — déconnecté, chat temporaire, fenêtre privée neuve à chaque passage

    Perplexity — déconnecté, fenêtre privée neuve à chaque passage, aucun historique

      La boucle, pour chaque ligne : clic sur « Ouvrir » → vérifier d'abord que la session est bien déconnectée et, sur ChatGPT, que le chat temporaire est actif → bannière cookies traitée avant que la réponse s'affiche → attendre la réponse complète → copier l'URL entière → copier le texte intégral dans un .txt → Cmd + Maj + 3 (plein écran, l'horloge doit être dans l'image) → cocher ici.

      Le nom de fichier exact s'affiche sous la ligne au moment où tu cliques « Ouvrir ». Il porte l'heure de ce clic. Le bouton copier le met dans le presse-papier.
      Si un moteur bloque — quota, mur de connexion, réponse tronquée : on ne recommence pas et on ne contourne pas. Clic sur bloqué, capture de l'écran de blocage quand même, et la série s'arrête pour ce moteur. Le blocage est le résultat, pas un incident à effacer. C'est exactement ce que le 17 septembre a appris.
